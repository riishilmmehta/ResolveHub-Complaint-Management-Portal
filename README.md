## 🌟 Overview

**ResolveHub** is a modern, feature-rich complaint management system designed for universities, organizations, and institutions. Built as a single-page React application, it provides a complete complaint lifecycle management solution with role-based access, real-time tracking, and analytics.

> **⚡ No installation required! Just open the HTML file in your browser and start managing complaints instantly.**

---

## ✨ Key Features

### 🔐 Multi-Role System
| Role | Access Level |
|------|--------------|
| 👑 **Admin** | Full system control, analytics, user management, audit logs |
| 🎓 **Student** | Submit and track complaints, add comments, give feedback |
| 👨‍🏫 **Teacher** | Submit and track complaints with teacher profile |
| 👨‍💼 **Staff** | Handle assigned complaints, update progress, add resolution notes |

### 📋 Complaint Management
- ✅ Submit complaints with categories, priorities, and attachments
- ✅ Anonymous submission option
- ✅ Real-time status tracking (Submitted → Under Review → Assigned → In Progress → Resolved → Closed)
- ✅ Complete complaint timeline with events
- ✅ Comments and communication system
- ✅ Feedback and rating system (1-5 stars)

### 📊 Analytics Dashboard
- Real-time statistics (Total, Pending, Resolved, Critical)
- Category distribution
- Priority breakdown
- Resolution rate and average resolution time
- Department-wise complaint distribution
- Filter by date range

### 🔔 Notification System
- Real-time notifications for status changes
- Assignment alerts
- Comment notifications
- Unread counter with mark as read

### 🎨 Premium UI/UX
- Glass morphism design
- Smooth animations and transitions
- Dark/Light mode with persistence
- Fully responsive (Desktop, Tablet, Mobile)
- Modern gradient color scheme
- Micro-interactions and hover effects

### 📦 Data Management
- Browser localStorage persistence
- Demo data pre-populated (10+ complaints)
- Export functionality (CSV/JSON)
- Audit logging
- Demo data reset
