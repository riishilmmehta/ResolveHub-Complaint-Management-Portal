## 🌟 Overview

**ResolveHub** is a modern, feature-rich complaint management system designed for universities, organizations, and institutions. Built as a single-page React application, it provides a complete complaint lifecycle management solution.

> **⚡ No installation required! Just open the HTML file in your browser.**

---

## ✨ Features

### 🔐 Multi-Role System
- **Admin** - Full system control, analytics, user management
- **Student** - Submit and track complaints
- **Teacher** - Submit and track complaints
- **Staff** - Handle assigned complaints

### 📋 Complaint Management
- Submit complaints with categories, priorities, and attachments
- Anonymous submission option
- Real-time status tracking
- Complete complaint timeline
- Comments and feedback system

### 📊 Analytics Dashboard
- Real-time statistics
- Category and priority distribution
- Resolution rate and average resolution time

### 🔔 Notification System
- Real-time notifications for status changes
- Assignment alerts
- Comment notifications

### 🎨 Premium UI/UX
- Glass morphism design
- Smooth animations
- Dark/Light mode
- Fully responsive
